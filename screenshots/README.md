# Ảnh chụp màn hình thực tế

Thư mục này dành cho ảnh chụp sản phẩm sau khi chạy website.

Tên file được đề xuất:

- `desktop-home.png`: trang chào mừng trên máy tính.
- `desktop-chat.png`: một cuộc trò chuyện Gemini đã phản hồi thành công.
- `mobile-view.png`: giao diện trên điện thoại.

Chỉ thêm ảnh chụp thật từ trình duyệt. Không dùng hình minh họa SVG trong `assets/images/` thay cho bằng chứng kiểm thử. Trước khi tải ảnh lên GitHub công khai, hãy che API Key, email và thông tin cá nhân.
